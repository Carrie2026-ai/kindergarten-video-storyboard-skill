# 幼儿园教育视频分镜助手

一个面向幼儿园教师与教研人员的 **教育视频脚本 / 分镜 Skill**。

它帮助用户把课程主题、活动复盘、教育观点、图文内容或口播想法，快速整理成适合幼儿园场景传播的视频方案。

## 它能做什么

- 口播视频脚本
- 教育观点短视频
- 活动复盘视频
- 图文改视频方案
- 配图视频分镜
- 生图转视频脚本
- 教研分享视频结构

## 核心特点

- 先想清楚“这条视频到底要表达什么”；
- 默认适配教师个人可完成的制作流程；
- 分镜数量克制，便于落地；
- 适合口播、剪映剪辑、AI 生图转视频；
- 强调教育真实性，不靠煽情和空话撑内容。
